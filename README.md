# 🎈 2D Çarpma Oyunu (Math Balloon Shooter)

Unity oyun motoru kullanılarak geliştirilmiş, oyuncuların çarpma işlemi becerilerini eğlenceli ve dinamik bir şekilde test eden 2D bir eğitim oyunudur. 

Oyunun temel mekaniğinde ekranda rastgele bir çarpma işlemi belirir ve üst kısımda süzülen 3 farklı renkli balonda olası cevaplar yer alır. Oyuncunun amacı, havan topu mekanizmasını kullanarak doğru cevabın bulunduğu balonu verilen süre içerisinde isabet ettirmektir. 

🚀 **Hemen Oyna:** Oyunun oynanabilir Android versiyonuna (APK) repo içerisinden doğrudan ulaşabilirsiniz. Sadece APK dosyasını Android cihazınıza indirip kurmanız yeterlidir.

### ✨ Temel Özellikler
*   **Eğitici ve Dinamik Oynanış:** Matematiksel düşünme hızını artıran rastgele çarpma işlemleri.
*   **Havan Topu Mekaniği:** Doğru balonu hedefleyip vurmak için tasarlanmış, animasyon destekli atış sistemi.
*   **Anlık Geri Bildirim (Feedback):** Doğru veya yanlış balon vurulduğunda oyuncuya durumu anında bildiren reaksiyon sistemi.
*   **Zaman Kısıtlaması:** Belirli bir süre içinde doğru cevabı bulmayı gerektiren, heyecan verici geri sayım sistemi.
*   **Mobil Uyumlu Çıktı:** Android cihazlarda sorunsuz çalışacak şekilde derlenmiş hazır APK.

### 🛠️ Kullanılan Teknolojiler
*   **Oyun Motoru:** Unity (2D)
*   **Programlama Dili:** C#
*   **Platform:** Android (APK)
